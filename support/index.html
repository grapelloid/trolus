Common questions

My request to localhost fails on iPhone

On a real iPhone, localhost and 127.0.0.1 point to the phone itself, not to your computer. Use your computer's address on the local network instead, for example http://192.168.1.20:8080, and make sure the server listens on all interfaces, not only on 127.0.0.1.

The first time you reach a local address, iOS asks for permission to use the local network. If you declined, turn it back on in Settings › Privacy & Security › Local Network › Trolus.

Can I send plain HTTP, not only HTTPS?

Yes. Trolus sends both http:// and https:// requests, so you can test development servers that have no certificate. If you leave out the scheme, Trolus adds http://.

How do environments and variables work?

In Settings › Environments, create an environment such as local or staging and add variables to it, for example base = https://api.example.com.

Write {{base}}/users in the URL and Trolus fills in the value of the active environment. Variables work in the URL, query parameters, headers, body and auth token. Switch environments from the menu at the top of the Request screen.

Which methods, bodies and auth types are supported?

Methods: GET POST PUT PATCH DELETE, plus HEAD and OPTIONS.

Bodies: JSON, plain text and URL-encoded form. Auth: Bearer token and Basic (username and password). Trolus adds Content-Type and Authorization for you unless you set them yourself in Headers.

A request hangs or times out

The default timeout is 30 seconds. Change it in Settings › Network, from 5 to 120 seconds. You can also cancel a request in progress from the response screen.

Where is my history stored, and how do I delete it?

Trolus keeps your last 200 requests with their responses on your iPhone only. Swipe left on a request in History to delete it, or tap Clear in History or Clear history in Settings to remove everything. Deleting the app removes all of its data. See the privacy policy for details.

Why are some keys in a JSON response not where I expect?

They are. Trolus formats JSON in the exact key order the server sent. If the order looks different from another tool, that tool is sorting the keys.

  • An internet connection or access to the local network where your server runs
